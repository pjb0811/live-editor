# Localization

The editor's own text is English by default: the section toolbar, the panel,
empty states, error messages, what a screen reader hears during a drag, and
validation messages. Pass `messages` to `Live` to replace any of it.

```tsx
import Live, { type LiveMessagesInput } from '@jbpark/live-editor';

// Defined once, outside the component.
const messages = {
  section: { delete: '섹션 삭제' },
  panel: { selectSection: '섹션을 선택하세요.' },
  validation: { max: max => `${max} 이하여야 합니다.` },
} satisfies LiveMessagesInput;

<Live messages={messages}>
  <Live.Dnd value={code} onChange={setCode} />
</Live>;
```

- **Partial, by group.** Give only the keys you want to change. Every other key
  keeps its English default.
- **Functions for text with values.** A message that includes a label, a
  count or a limit is a function, so a translation can put the value where its
  grammar needs it.
- **Define it once.** A new object on every render re-renders everything that
  shows text. Keep it at module level, or memoize it.
- **Nested `Live`s inherit.** A `Live` inside another starts from the outer
  one's messages, with its own on top. One `Live` around a page can set the
  language for every editor in it.

## Groups

| Group           | Where it shows                                                                               |
| --------------- | -------------------------------------------------------------------------------------------- |
| `section`       | The section toolbar on the canvas and the panel header: move, duplicate, delete.             |
| `canvas`        | Empty states, the drop zone, the element picker, the mobile Drawer titles, the stale banner. |
| `panel`         | The panel's notices, placeholders and the fallback validation message.                       |
| `items`         | The built-in editor for an array value.                                                      |
| `children`      | The built-in editor for child elements.                                                      |
| `selection`     | The bar shown while items or children are selected.                                          |
| `editErrors`    | The `title` and `description` of every `DndEditError`, which the default toast shows.        |
| `announcements` | What a screen reader hears during a drag, and the drag instructions.                         |
| `errors`        | The error boxes of `Live.Preview`, `Live.Error` and canvas sections.                         |
| `validation`    | `validateBindingValue`'s messages. See [below](#validation).                                 |

`LiveMessages` is the full type, and `defaultMessages` the English set, both
exported from `@jbpark/live-editor`.

A minor version can add keys, and they show in English until you translate
them. Renaming or removing a key waits for a major version. A set typed as the
full `LiveMessages`, like the [Korean one below](#a-complete-korean-set), stops
compiling when a key is added, which is how you find the new text.

Text that comes from elsewhere stays as it is: section and field names come
from your documents and bindings, and compiler messages from Babel.

## In a custom palette or panel

`useLiveMessages()` returns the messages in effect, so your own components can
show the same text as the built-in ones:

```tsx
import { useLiveMessages } from '@jbpark/live-editor';

const DeleteButton = ({ onClick }: { onClick: () => void }) => {
  const messages = useLiveMessages();

  return <button onClick={onClick}>{messages.section.delete}</button>;
};
```

`onEditError` receives the translated `title` and `description` too.

## Validation

`validateBindingValue` is a plain function, so it takes its messages as an
option. The built-in panel passes the provider's `validation` group. A custom
panel can do the same:

```ts
import { validateBindingValue } from '@jbpark/live-editor/utils/ast';

const messages = useLiveMessages();
const result = validateBindingValue(binding, value, {
  messages: messages.validation,
});
```
