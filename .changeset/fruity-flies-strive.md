The outline a panel field draws on its element now follows the element when an edit moves or resizes it, not only when the canvas scrolls or the window resizes. The element picker's Escape key and the error guard's `unhandledrejection` handling work as before. `@jbpark/use-hooks` is now `^4.6.0` and `@jbpark/ui-kit` `^10.3.0`.
